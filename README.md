# Проект парсинга pep

Парсер документации Python и PEP (Python Enhancement Proposals).

## Описание

Проект представляет собой набор парсеров для сбора информации с сайтов документации Python и PEP. Парсеры собирают информацию о новых возможностях Python, версиях документации, а также анализируют статусы всех PEP с подсчетом статистики.

## Возможности

- **whats-new** - парсинг статей о новых возможностях Python
- **latest-versions** - получение информации о версиях документации
- **download** - скачивание архива с документацией
- **pep** - парсинг всех PEP с подсчетом статусов

## Установка

```bash
# Клонирование репозитория
git clone <your-repo-url>
cd bs4_parser_pep

# Создание и активация виртуального окружения
python -m venv venv
source venv/bin/activate  # для Linux/Mac
# или
venv\Scripts\activate  # для Windows

# Установка зависимостей
pip install -r requirements.txt
```

## Использование

### Базовые команды

```bash
# Парсинг новостей What's New
python src/main.py whats-new

# Парсинг версий Python
python src/main.py latest-versions

# Скачивание документации
python src/main.py download

# Парсинг PEP
python src/main.py pep
```

### Дополнительные опции

```bash
# Вывод результатов в виде таблицы
python src/main.py <mode> -o pretty

# Сохранение результатов в CSV файл
python src/main.py <mode> -o file

# Очистка кеша перед запуском
python src/main.py <mode> -c

# Получение справки
python src/main.py -h
```

### Примеры для режима PEP

```bash
# Вывод статистики по статусам PEP в консоль
python src/main.py pep -o pretty

# Сохранение результатов в CSV файл
python src/main.py pep -o file

# Очистка кеша и запуск парсера PEP
python src/main.py pep -c -o pretty
```

## Результаты работы

### Режим PEP

Парсер собирает информацию о всех PEP, извлекает статус со страницы каждого PEP и сравнивает его с ожидаемым статусом из общей таблицы. Результаты сохраняются в CSV файл с двумя колонками: "Статус" и "Количество".

Пример вывода:

```
+-------------+------------+
| Статус      | Количество |
+-------------+------------+
| Accepted    | 26         |
| Active      | 38         |
| April Fool! | 1          |
| Deferred    | 36         |
| Draft       | 43         |
| Final       | 357        |
| Rejected    | 130        |
| Superseded  | 25         |
| Withdrawn   | 70         |
| Total       | 726        |
+-------------+------------+
```

Всего обработано 726 PEP.

### Несовпадающие статусы

При обнаружении расхождений между статусом в таблице и статусом на странице PEP, информация выводится в консоль и логи:

```
Несовпадающие статусы:
https://peps.python.org/pep-0401/
Статус в карточке: April Fool!
Ожидаемые статусы: [Rejected]
```

## Технологии

- Python 3.12+
- BeautifulSoup4 - парсинг HTML
- requests-cache - кеширование запросов
- tqdm - прогресс-бары
- prettytable - форматирование таблиц
- pytest - тестирование

## Требования

- Python 3.12 или выше
- Установленные зависимости из requirements.txt

## Примечания

- При первом запуске парсера PEP загрузка всех страниц может занять 5-10 минут
- Для ускорения последующих запусков используется кеширование
- Все ошибки и предупреждения логируются в файлы в директории `logs/`
